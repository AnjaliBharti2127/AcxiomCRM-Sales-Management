# Viva guide
**MVC?** Model represents data, View renders UI, Controller receives requests.
**EF Core?** ORM translates LINQ into SQL and tracks changes.
**Identity?** Framework for user credentials, password hashing, roles and lockout.
**Authentication vs authorization?** Who you are versus what you can access.
**Why server validation?** Browser requests can be manipulated.
**CSRF?** An attacker tricks a signed-in browser into sending unwanted requests; antiforgery tokens mitigate this.
**DTO?** Explicit API/form fields prevent exposing internal fields and overposting.
**Weighted pipeline?** Sum of each open deal amount times its probability divided by 100.
**Audit log?** Append-oriented record of user actions for accountability.
**Why transactions?** Related changes succeed together or roll back together.
