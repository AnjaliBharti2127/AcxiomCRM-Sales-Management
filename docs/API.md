# API usage
Use HTTPS and a cookie jar (Postman or browser). GET /api/auth/csrf, retain cookies and copy token. POST /api/auth/login with JSON {"email":"admin@example.test","password":"YOUR_LOCAL_PASSWORD"} and header X-CSRF-TOKEN. GET /api/auth/csrf again after login, use new token for all POST/PUT/DELETE requests. GET /api/customers, /api/leads, /api/opportunities, /api/followups, /api/activities. Each supports GET /{id}, POST, PUT /{id}, DELETE /{id}. GET /api/reports/pipeline returns grouped pipeline data. POST /api/auth/logout with CSRF token. Never commit cookies or passwords.
